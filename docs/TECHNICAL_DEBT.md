# Technical Debt

## Social Fast Path Variation

Estado: adiado.

O caminho rápido social responde atualmente a saudações simples como "Olá" com uma frase fixa. Isto é intencionalmente seguro e não inventa contexto, mas torna a conversa repetitiva.

Melhoria futura:

- variar respostas sociais de forma controlada;
- usar apenas contexto real e recente;
- nunca inventar estado emocional, atividade ou disponibilidade;
- manter respostas curtas e em português de Portugal;
- não chamar o LLM para saudações triviais salvo decisão explícita futura.
