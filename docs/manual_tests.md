# Testes manuais

## Campo de mensagem

1. Abrir a aplicação.
2. Escrever uma mensagem curta.
3. Premir Enter.
4. Assim que a resposta terminar, escrever outra mensagem sem tocar no rato.
5. Confirmar que o cursor continua no campo de entrada.

Atalhos:
- Enter envia a mensagem.
- Ctrl+Enter cria uma nova linha no campo de entrada.
- Esc limpa apenas o texto atual da caixa de entrada.
- Ctrl+L limpa a conversa.
