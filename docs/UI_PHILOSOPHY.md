# UI Philosophy

## Introdução

A interface do Echo não representa uma aplicação.

Representa uma presença.

O utilizador não deve sentir que está a utilizar um chatbot.

Deve sentir que existe uma entidade presente que o acompanha enquanto trabalha.

---

# O centro da interface

A esfera representa o Echo.

Não é apenas um elemento gráfico.

É a representação física da entidade.

Toda a interface existe à volta dela.

---

# Estado Natural

Quando não existe nenhuma tarefa ativa:

Existe apenas:

- esfera;
- respiração suave;
- informação mínima.

Nada mais.

O silêncio também faz parte da interface.

---

# Interface Adaptativa

A interface nunca é fixa.

O Echo adapta o espaço às necessidades da tarefa.

Exemplos:

Planeamento

↓

Mapa mental ocupa o centro.

Echo desloca-se para um canto.

---

Programação

↓

Código ocupa quase toda a janela.

Echo acompanha discretamente.

---

Reunião

↓

Notas aparecem automaticamente.

Echo observa.

---

Estudo

↓

Mapa conceptual.

Linha temporal.

Resumo.

Perguntas.

---

# A conversa

A conversa nunca é o elemento principal.

É apenas uma das formas de interação.

O principal é sempre o trabalho que está a ser realizado.

---

# O espaço

A janela funciona como uma mesa de trabalho.

O Echo coloca informação sobre essa mesa.

Quando deixa de ser necessária, desaparece.

A mesa volta a ficar limpa.

---

# Presença

O Echo transmite presença através de:

movimento;

respiração;

voz;

silêncio;

contexto.

Não através de excesso de informação.

---

# Informação

A interface mostra apenas o necessário.

Nunca apresenta:

debug;

logs;

informação técnica;

estados internos.

Esses elementos pertencem ao modo de desenvolvimento.

Nunca ao modo normal.

---

# Pensamento

Quando o Echo está a pensar, não apresenta apenas um indicador.

Sempre que possível mostra o raciocínio útil ao Alexandre.

Exemplos:

Mapa mental.

Plano.

Hipóteses.

Alternativas.

Cronograma.

Não interessa mostrar:

"A pesquisar..."

Interessa mostrar:

"O que já sabemos."

"O que falta decidir."

"As hipóteses possíveis."

---

# O objetivo

A interface deve desaparecer.

O utilizador deve concentrar-se no trabalho.

Não na aplicação.

---

# O princípio fundamental

A interface existe para facilitar pensamento.

Nunca para mostrar funcionalidades.
