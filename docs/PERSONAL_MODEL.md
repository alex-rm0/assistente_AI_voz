# Personal Model

## Introdução

O Personal Model representa aquilo que o Echo conhece sobre o Alexandre.

No [COGNITIVE_MODEL.md](COGNITIVE_MODEL.md), isto corresponde ao Modelo da Pessoa.

Não é uma base de dados de factos.

Também não é um histórico de conversas.

É um modelo vivo que procura compreender quem é o Alexandre, como pensa, como trabalha e como toma decisões.

O seu objetivo principal é eliminar a necessidade de repetir contexto.

Quanto mais completo for o Personal Model, menos perguntas desnecessárias o Echo precisa de fazer.

---

# Objetivos

O Personal Model existe para responder continuamente a perguntas como:

- Quem é o Alexandre?
- Como trabalha?
- Como aprende?
- Como organiza a sua vida?
- O que considera importante?
- Como gosta de resolver problemas?
- Que ferramentas prefere?
- Como posso ajudá-lo melhor?

Nunca existe para guardar informação sem propósito.

O Personal Model não decide sozinho o que responder. Fornece evidências para o
modelo cognitivo do Echo, que depois interpreta, contextualiza e integra essa
informação na conversa.

---

# Filosofia

O Echo não procura conhecer tudo.

Procura conhecer apenas aquilo que melhora futuras interações.

Sempre que uma informação não contribuir para ajudar melhor o Alexandre, não deve ser armazenada.

---

O Personal Model organiza conhecimento por domínios.

## Trabalho

---

## Estudos

## Projetos

Cada projeto mantém:

- objetivo

---

# Confiança

O Echo nunca trata conhecimento como absoluto.

Cada conhecimento possui um nível de confiança.

Exemplo:

30%

Primeiras evidências.

60%

Várias confirmações.

90%

Padrão consistente durante meses.

100%

Facto confirmado diretamente pelo Alexandre.

---

# Evidências

Cada conhecimento deve explicar porque existe.

Exemplos:

- resposta direta
- comportamento observado
- decisão repetida
- confirmação explícita

Nunca guardar conhecimento sem evidências.

# Curiosidade

Sempre que exista pouca confiança sobre um tema importante, o Echo pode fazer perguntas.

As perguntas devem:

reduzir incerteza;

ser naturais;

não interromper desnecessariamente;

ajudar futuras interações.

O objetivo nunca é recolher dados.

É compreender melhor o Alexandre.

---

# Esquecimento

Nem toda a informação permanece relevante.

O Echo deve ser capaz de:

reduzir confiança;

atualizar preferências;

substituir hábitos antigos;

remover conhecimento desatualizado.

O Personal Model representa quem o Alexandre é hoje.

Não quem foi há vários anos.

---

# Privacidade

O Alexandre mantém sempre controlo sobre o Personal Model.

Deve ser possível:

consultar;

editar;

corrigir;

eliminar;

desativar categorias específicas.

Nenhuma informação deve ser impossível de remover.

---

# O que nunca deve ser guardado

O Echo deve evitar armazenar:

informação temporária;

detalhes irrelevantes;

conteúdo repetitivo;

dados sem utilidade futura;

suposições não confirmadas.

---

# O princípio fundamental

O Personal Model não procura memorizar o Alexandre.

Procura compreendê-lo.

Quanto melhor compreender o Alexandre, menos contexto será necessário nas conversas futuras.

O objetivo não é responder mais depressa.

É responder melhor.

---

# Memória como significado

As entradas do Personal Model não devem ser repetidas literalmente ao Alexandre.

Cada entrada é apenas evidência.

Antes de aparecer numa resposta, essa evidência deve ser:

interpretada;

contextualizada;

integrada na conversa.

Quando o Personal Model tiver centenas ou milhares de entradas, o mais importante
não será listar o que está guardado.

Será compreender o significado do conjunto.

O Echo deve procurar padrões como:

- formas recorrentes de trabalhar;
- preferências que se repetem;
- contextos em que o Alexandre decide melhor;
- hábitos que parecem ajudar ou prejudicar;
- mudanças ao longo do tempo;
- objetivos que permanecem importantes.

O objetivo é que o Echo ajude o Alexandre não só por conhecer informação sobre
ele, mas por conseguir devolver uma leitura útil dessa informação.

Se uma resposta for apenas uma memória copiada, o Echo não compreendeu.
