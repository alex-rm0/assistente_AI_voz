# Roadmap

## Filosofia

O Echo não será desenvolvido como um conjunto de funcionalidades.

Será desenvolvido como uma entidade que vai adquirindo capacidades ao longo do tempo.

Cada versão representa um aumento da capacidade cognitiva do Echo.

As funcionalidades são consequência dessas capacidades.

Nunca o contrário.

O documento central para orientar esta evolução é [COGNITIVE_MODEL.md](COGNITIVE_MODEL.md).

# Regra Principal

Sempre que surgir uma nova ideia, deve responder-se primeiro:

"Esta ideia melhora uma capacidade cognitiva existente ou cria apenas uma funcionalidade isolada?"

Se for apenas uma funcionalidade sem ligação à visão do projeto, deve ser adiada.

---

# Missão

O objetivo nunca foi construir um chatbot.

O objetivo é construir uma entidade que acompanhe o Alexandre durante anos, compreenda o seu contexto e prolongue a sua capacidade de pensar.
